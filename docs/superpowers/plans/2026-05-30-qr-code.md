# QR Code on Card Front — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Display a build-time-generated QR code in the bottom-right corner of the business card front face, encoding the card's own URL.

**Architecture:** `index.astro` generates a QR SVG string at build time using the existing `qrcode` devDependency, then passes it as a prop to `CardFront`. `CardFront` renders it as an absolutely-positioned inline SVG with `set:html`. Zero runtime JavaScript added.

**Tech Stack:** Astro (SSG), `qrcode` npm package (already installed as devDependency), CSS container queries (`cqi` units).

### Task 2: Generate QR SVG in `index.astro`

**Files:**
- Modify: `src/pages/index.astro`

- [ ] **Step 1: Add `qrcode` import**

In `src/pages/index.astro`, add this import after the existing imports (inside the `---` frontmatter block):

```ts
import QRCode from "qrcode";
```

- [ ] **Step 2: Generate the SVG string**

Add this block after `const cardData: CardData = { ... }` and before `const pageTitle = ...`:

```ts
const cardUrl = import.meta.env.CARD_URL ?? "https://business-card.riumu.net";
const qrSvg: string = await QRCode.toString(cardUrl, {
  type: "svg",
  errorCorrectionLevel: "H",
  margin: 1,
});
```

- [ ] **Step 3: Pass `qrSvg` to `CardFront`**

Find this line in the template:

```astro
<CardFront profile={cardData.profile} />
```

Replace with:

```astro
<CardFront profile={cardData.profile} qrSvg={qrSvg} />
```

- [ ] **Step 4: Verify build compiles**

```bash
npm run build
```

Expected: build succeeds. If TypeScript complains about `QRCode` types, the `@types/qrcode` package is not installed — but `qrcode` ships its own types, so this should pass.

- [ ] **Step 5: Commit**

```bash
git add src/pages/index.astro
git commit -m "feat: generate QR SVG at build time in index.astro"
```

### Task 3: Render QR in `CardFront.astro`

**Files:**
- Modify: `src/components/CardFront.astro`

- [ ] **Step 1: Add `qrSvg` to the Props interface**

Find:

```ts
interface Props {
  profile: Profile;
}
```

Replace with:

```ts
interface Props {
  profile: Profile;
  qrSvg: string;
}
```

- [ ] **Step 2: Destructure the new prop**

Find:

```ts
const { profile } = Astro.props;
```

Replace with:

```ts
const { profile, qrSvg } = Astro.props;
```

- [ ] **Step 3: Render the QR element**

Find the closing `</section>` tag at the end of the template (just before `<style>`):

```astro
  </div>
</section>
```

Replace with:

```astro
  </div>

  <div class="card-front__qr" set:html={qrSvg} aria-hidden="true" />
</section>
```

- [ ] **Step 4: Add `position: relative` to `.card-front`**

In the `<style>` block, find the `.card-front` rule and add `position: relative;`:

```css
.card-front {
  height: 100%;
  display: grid;
  grid-template-columns: minmax(0, 33%) minmax(0, 1fr);
  gap: 5cqi;
  padding: 4cqi;
  align-items: center;
  box-sizing: border-box;
  position: relative;
}
```

- [ ] **Step 5: Add QR styles**

At the end of the `<style>` block (before the closing `</style>`), add:

```css
.card-front__qr {
  position: absolute;
  bottom: 2.5cqi;
  right: 2.5cqi;
  width: 13cqi;
  height: 13cqi;
  background: white;

  box-sizing: border-box;
```
